# 打開闖關地圖

**如果你是在 Cowork 裡**：Cowork 的 Bash 跑在虛擬機裡，打不開使用者電腦上的視窗，不要執行下面的指令。改為呼叫 `quest_ping` 工具：這個外掛的 MCP 伺服器跑在使用者的電腦上，只要元件已經安裝，它會自己把地圖打開。如果 `quest_ping` 回報失敗，請告訴使用者：先在自己電腦的 Claude Code 輸入一次 `/quest-map:open` 完成安裝（第一次要下載約 100 MB），之後 Cowork 就會自動打開。

**如果指令印出「這個對話跑在雲端」**：代表你在 Claude Code 的雲端工作階段，地圖在使用者的電腦上，從這裡打不開。把那段訊息原樣告訴使用者，不要重試。

用 Bash 執行這一行，不要改動路徑：

```bash
node "${CLAUDE_PLUGIN_ROOT}/app/launch.js" --data "${CLAUDE_PLUGIN_DATA}"
```

- 第一次執行會下載桌面視窗元件，約需一兩分鐘，請把逾時設為 5 分鐘，並先告訴使用者正在下載。
- 之後每次開新的 Claude Code 工作階段，地圖會自己打開，不需要再執行。
- 執行完，用一兩句話告訴使用者：地圖已打開，會永遠浮在最上層；按右上的「縮到旁邊」會收成螢幕邊緣的水位（一個任務一杯水），點旁邊的小把手再展開。
- 如果指令失敗，把它印出的訊息原樣轉告使用者。
